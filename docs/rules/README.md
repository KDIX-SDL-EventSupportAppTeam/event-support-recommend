## 絶対に守ること（要約）

1. **成功の定義を外さない。** 踏破率ではない。「自分では選ばなかったブースへ行き、新しい興味になる」こと。
   **人気順の推薦は失敗である**
2. **契約の内容をこのリポジトリにコピーしない。** リンクで参照する
3. **500 を返さない。** どんな入力でも 200 を返す
4. **`scores` は候補全件。** 1件も落とさない。判定可能なのに `UNKNOWN` を返さない
5. **DB に書き込まない。** このサービスは読むだけ
6. **未決定事項を勝手に決めない。** [docs/README.md](../README.md) の一覧を参照する
