# 当日のフェーズ切り替え（段3・段4 の結線）

**イベント当日、データが溜まるにつれて推薦戦略が自動で切り替わるようにするための仕様。**
これが動かないと、フェーズ設計は「判定するが使わない」飾りになり、
研究として主張できるものが `COVERAGE` 1本に縮む。

## 何が足りていないのか

判定の仕組みも戦略の仕様も揃っている。**足りないのはデータ供給と、判定結果を使う1行である。**

```
現状:  decide_phase() → judged_phase → ログに出るだけ
       actual_phase = Phase.COVERAGE          ← engine.py のハードコード
       rule_cache は空（put する者がいない）
       decision_table_size は常に None → 判定結果も常に COVERAGE
```

| 部品 | 状態 |
|---|---|
| フェーズ判定 `decide_phase()` / 品質ゲート | 実装済み・純関数・テスト済み |
| 退避（DRSA→SIMILARITY→COVERAGE）の仕様 | [04-strategies.md](../04-strategies.md) §5 に確定済み |
| DRSA コア（優越関係・近似・規則生成・γ） | 実装済み・純粋・テスト済み |
| 条件属性 `preference_match` / `rating_affinity` | 実装済み |
| `SIMILARITY` の近傍定義・ベイズ縮約 | [04-strategies.md](../04-strategies.md) §3 に数式まで確定済み。**実装のみ未** |
| `RuleCache` | 実装済み。**put される日を待っている** |
| `/ops/state` | 実装済み。中身が空なので `COVERAGE` を返しているだけ |

| **`SIMILARITY` / `DRSA` の結線（段4）** | **未実装。本仕様の主題** |

## 絶対に守る制約

1. **リクエスト経路で DB を読まない・規則を生成しない。**
   解放は1000msでタイムアウトする。読むのはキャッシュだけ
2. **`phase` には「判定結果」ではなく「実際に使った戦略」を返す。**
   判定は DRSA だが中身は COVERAGE、という行が残ると解釈不能になる
3. **どんな失敗でも 200 を返す。** スナップショットが取れなくても `COVERAGE` は必ず動く
4. **取得に失敗したとき、キャッシュを空にしない。** 前回の規則を持ち続ける
5. **`visitor_count` を `SIMILARITY` / `DRSA` のスコアに混ぜない。** 人気度が復活する
6. **当日パラメータを変更しない**（[ADR 0009](../../decisions/adrs/0009-当日の切り替えは既定値のまま走らせ調整は事後に行う.md)）

## パラメータの扱い

**既定値のまま走らせる。細かい調整は事後に行う**（[ADR 0009](../../decisions/adrs/0009-当日の切り替えは既定値のまま走らせ調整は事後に行う.md)）。

`docs/README.md` の「未決定事項の一覧」に載っている9件は、
**未決定のまま既定値で本番に出す。** 決めたのは値ではなく「今回は既定値で走らせる」ことである。
実装時に値を確定値として書き換えない。

## 到達しない可能性について

決定表は**評価済みの件数**である。評価回収率が低ければ、当日 `DRSA`（既定60件）はおろか
`SIMILARITY`（既定30件）にも到達しないことがありうる。

**到達しないこと自体は失敗ではない。** 失敗なのは、到達していないのに到達したふりをすることである。
到達しなかった場合も、`card_unlock_events.phase` に `COVERAGE` が並ぶという事実が研究データになる。

## この仕様が完了したときに起きること

- 当日、評価が溜まるにつれて `COVERAGE` → `SIMILARITY` → `DRSA` と自動で切り替わる
- 切り替わりは `card_unlock_events.phase` に記録され、**事後に「フェーズ別の比較」ができる**
- 運営ダッシュボードに出るフェーズが、推薦エンジンの実際の状態と一致する
  （サーバー側の独自計算を廃止する。`event-support-server/docs/specs/recommender-phase-linkage/`）
